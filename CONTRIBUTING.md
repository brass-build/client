# Contributing

This repository is a **read-only publish mirror** for the `@brass-build/client`
npm package. The source is developed in a private repository and synced
here on every release, then published to npm with provenance from this
repo.

Because the sync overwrites this repo on each release, changes made here
directly cannot be accepted:

- **Issues** are disabled. To report a bug or request a change, reach us
  at https://brass.build.
- **Pull requests** opened here are closed automatically, since a later
  sync would overwrite them.

The published package and its `README.md` are the supported surface.
